# Zamani African Heritage Kitchen — AUMA Website Demo

A responsive restaurant concept website built with **React, TypeScript, Vite and Tailwind CSS**. This repository contains the editable application source code and an automatic GitHub Pages deployment workflow.

## Local development

Prerequisites: **Node.js 22** and npm.

```bash
npm install
npm run dev
```

Open the local address printed by Vite (usually http://localhost:3000).

To verify your changes before sharing:

```bash
npm run lint
npm run build
npm run preview
```

`dist/` is generated by the build and should not be committed.

## Edit your own content

| What you want to change | Where to edit |
| --- | --- |
| Restaurant name, contact number, WhatsApp number, London address, hours, chef, ratings | `src/data/restaurantData.ts` → `RESTAURANT_INFO` |
| Dishes, descriptions, menu prices and categories | `src/data/restaurantData.ts` → `MENU_ITEMS` |
| Food photos | `public/images/` and `DISH_IMAGES` in `restaurantData.ts` |
| Main hero/sections/buttons | `src/components/` |
| AUMA attribution watermark | `src/App.tsx` |
| Colors and typography | `src/index.css` |
| SEO page title and social previews | `index.html` |

## Publish automatically on GitHub Pages

1. Create a GitHub repository (e.g. `zamani-african-heritage-kitchen`).
2. Upload **the contents of this folder** to the repository root, including the `.github/workflows/deploy.yml` folder, and commit on the `main` branch. For the Git CLI:

   ```bash
   git init
   git add .
   git commit -m "Prepare Zamani demo for GitHub Pages"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO.git
   git push -u origin main
   ```

3. In the GitHub repository choose **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. In **Actions**, wait for the "Deploy website to GitHub Pages" run to complete. Open the Pages link in Settings → Pages.

For a normal project repository your URL will look like:

`https://YOUR-USERNAME.github.io/YOUR-REPO/`

The build automatically detects the repository name, so photos and assets resolve even if the repository name changes. Each new push to `main` triggers a new build.

## Important: demo-only features and placeholder content

- **Reservations are not real bookings.** Booking drafts and selected dishes are stored in the visitor's browser using `localStorage`. No central database, email delivery, live availability check, restaurant notification or booking backend exists. The UI now labels bookings as drafts and asks visitors to send a WhatsApp request for human confirmation.
- **Contact information is sample content.** The London address, phone, WhatsApp number, email, named chef, accolades, star rating and menu prices must be verified/replaced before offering this website as a real restaurant business website.
- GitHub Pages supports the static frontend and external WhatsApp links, **not server-side reservation processing**. A real booking backend requires another service, an API, or an external booking provider.
- The page uses Google Fonts loaded online.
